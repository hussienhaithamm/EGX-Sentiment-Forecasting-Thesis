\chapter{Conclusion \& Future Work}
\label{chap:conclusion}

This chapter answers the three research questions, summarises what was built, and outlines five directions for future work. No new results appear here; every number refers back to Chapter~\ref{chap:results}.

\section{Conclusion}

This thesis tested whether bilingual financial-news sentiment supports short-horizon EGX stock forecasting under a conservative and reproducible evaluation design. The study began from an industrial motivation: sentiment appeared useful as an additional signal inside an existing historical price-based forecasting model. The re-run of that integration experiment showed conditional gains rather than uniform improvement. Sentiment improved raw accuracy in 5 of 9 ticker-model comparisons, with the strongest gain for OIH using an MLP, but it reduced performance in other settings. The result was useful as motivation rather than a clean final claim. This directly answers RQ3: gains seen under a richer feature setup do not hold up once the evaluation moves to a strict sentiment-only benchmark.

The core contribution of the thesis is the sentiment-only benchmark itself, which addresses RQ1 and RQ2. The implemented pipeline collects Arabic and English Mubasher company news, routes English articles to FinBERT and Arabic articles to an AraBERT-based sentiment route, aggregates article-level sentiment into lagged daily features through the confidence filter and weighted aggregation in equations (\ref{eq:confidence_filter})--(\ref{eq:daily_aggregation}), and evaluates all-news, event-only, and event-weighted variants under chronological walk-forward validation. The final accepted result is modest. The strongest validity-passing candidate is OIH at the 5-day horizon under the all-news bilingual setting, with test accuracy 0.425, balanced accuracy 0.503, F1 0.021, and return sign accuracy 0.585. These numbers point to a weak signal rather than a reliable standalone forecasting system. Sign accuracy (0.585) is the more useful metric here because the near-zero F1 reflects the classifier collapsing toward one class after threshold selection, not a complete absence of signal. Event filtering gave a small positive average accuracy gain ($+0.025$ for event-only, $+0.032$ for event-weighted), though it was concentrated in a few panels. That is the direct answer to RQ2: event-aware aggregation helps selectively but not consistently.

The mixed results are still scientifically useful. Leakage checks passed across 45 panel evaluations and 43{,}880 prediction rows, while overfitting analysis flagged 14 of those 45 rows. The strongest raw-accuracy event-weighted candidate was therefore treated as exploratory rather than accepted. A separate correlation study found no stable monotonic link between sentiment and returns. Taken together, these checks support the main conclusion: bilingual financial-news sentiment carries some signal in this EGX setting, but the signal is sparse, unstable, and very sensitive to coverage, horizon, and how strictly the evaluation is run.

\section{Future Work}

The most immediate future step is to improve data coverage. An incremental scrape run at submission time expanded the dataset from 1{,}912 to 1{,}921 articles, recovering 17 new raw records (CIB~$+8$, TMG~$+7$, OIH~$+2$) of which 9 passed the medium-confidence entity filter. Prior-7-day article coverage remains 0.569 for CIB, 0.387 for TMG, and 0.307 for OIH, which confirms that sparse text histories limit signal stability for TMG and OIH. Broader source coverage should be considered for future work, but only if ticker linkage and timestamp quality remain auditable. Possible additions include official company disclosures, Egyptian Exchange announcements, and other financial-news providers with stable archives.

A second direction is Arabic financial-domain adaptation. The thesis prepares and tests the first stage of this process by running a short Masked Language Modeling (MLM) adaptation of AraBERT on 1{,}327 Arabic financial articles. The adapted checkpoint reduces held-out MLM loss relative to base AraBERT under matched seed, tokenizer, and evaluation script. This measures domain language modelling fit, not supervised sentiment performance, which remains future work pending Arabic financial sentiment labels. A valid Arabic FinBERT-style model still requires independent human-labeled Arabic financial sentiment examples for supervised fine-tuning and evaluation. The next step would be to build a small expert-labeled Arabic financial sentiment set with positive, negative, and neutral labels, check inter-annotator agreement, fine-tune the adapted encoder with a classification head, and compare it against the current AraBERT route on held-out human labels. Using model-generated labels as ground truth only copies the existing classifier; it does not show real improvement in sentiment quality.

A third direction is controlled integration with market features. The historical integration experiment suggests that sentiment may help selected model-ticker pairs when added to price-derived features. That experiment should be repeated with a fully unified target definition, walk-forward protocol, and ablation design before making stronger claims. A stronger follow-up compares price-only, sentiment-only, and price-plus-sentiment models under the same target, embargo, validation, threshold-selection, and test-period rules.

A fourth direction is richer event modelling. The event-aware layer can be expanded beyond keyword-style categories. The present event labels are useful as a lightweight relevance signal, but they do not capture event materiality, novelty, or whether the article describes expected or surprising information. A future system trains a supervised event classifier, estimates event severity, and separates company-specific events from market-wide coverage.

The fifth direction is social media. Social media remains future work rather than a completed experiment. Reddit is potentially feasible only through official API or approved research access with strict data-handling limits. X/Twitter is not a free broad-search option under the current official API model. If approved access becomes available, the next design collects posts only through official channels, avoids redistribution of raw user content, maps Arabic and English aliases for EGX tickers, and compares news-only, social-only, news-plus-social, and ensemble models under the same leakage-safe evaluation framework used in this thesis.
