\chapter{Conclusion \& Future Work}
\label{chap:conclusion}
\section{Conclusion}

This thesis tested whether bilingual financial-news sentiment can support short-horizon EGX stock forecasting under a conservative and reproducible evaluation design. The study began from an industrial motivation: sentiment appeared useful as an additional signal inside an existing historical price-based forecasting model. Re-running that integration experiment showed conditional gains, but not uniform improvement. Sentiment improved raw accuracy in 5 of 9 ticker-model comparisons, with the strongest gain for OIH using an MLP, but it also reduced performance in other settings. This made the result useful as motivation rather than as a clean final claim.

The core contribution of the thesis is therefore the sentiment-only benchmark. The implemented pipeline collects Arabic and English Mubasher company news, routes English articles to FinBERT and Arabic articles to an AraBERT-based sentiment route, aggregates article-level sentiment into lagged daily features, and evaluates all-news, event-only, and event-weighted variants under chronological walk-forward validation. The final accepted result is modest. The strongest validity-passing candidate is OIH at the 5-day horizon under the all-news bilingual setting, with test accuracy 0.532, balanced accuracy 0.503, F1 score 0.630, and return sign accuracy 0.585. These values indicate weak informational value, not a strong standalone forecasting system.

The negative and mixed results are still scientifically useful. Leakage checks passed across 45 panel evaluations and 43,880 validation/test prediction rows, while overfitting analysis flagged 15 of 45 rows. The strongest raw-accuracy event-weighted candidate was therefore treated as exploratory instead of being promoted as the headline result. A separate sentiment-return correlation study also found no stable monotonic association under the pre-specified threshold. Together, these checks support the main conclusion: bilingual financial-news sentiment carries some signal in this EGX setting, but the signal is sparse, unstable, and highly sensitive to coverage, horizon, and validation discipline.

\section{Future Work}

The most immediate future step is to improve data coverage. The final audit found that TMG and OIH matched the currently available Mubasher listing pages, while CIB had one additional Arabic listing page available. Re-running the resumable scraper before final submission would reduce this residual incompleteness. Broader source coverage should also be considered, but only if ticker linkage and timestamp quality remain auditable. Possible additions include official company disclosures, Egyptian Exchange announcements, and other financial-news providers with stable archives.

A second direction is Arabic financial-domain adaptation. The thesis prepared and tested the first stage of this process by running a short masked-language-model adaptation of AraBERT on 1,327 Arabic financial articles. The adapted checkpoint reduced held-out masked-language-model loss relative to base AraBERT, but a valid Arabic FinBERT-style model still requires independent human-labeled Arabic financial sentiment examples for supervised fine-tuning and evaluation. The next research step should therefore construct a small expert-labeled Arabic financial sentiment set with positive, negative, and neutral labels, evaluate inter-annotator agreement, fine-tune the adapted encoder with a classification head, and compare it against the current AraBERT route on held-out human labels. Using the current model-generated labels as ground truth would only distill the existing classifier and would not prove improved sentiment quality.

A third direction is controlled integration with market features. The historical integration experiment suggests that sentiment may help selected model-ticker pairs when added to price-derived features, but that experiment should be repeated with a fully unified target definition, walk-forward protocol, and ablation design before making stronger claims. A stronger follow-up would compare price-only, sentiment-only, and price-plus-sentiment models under the same target, embargo, validation, threshold-selection, and test-period rules.

Fourth, the event-aware layer can be expanded beyond keyword-style categories. The present event labels are useful as a lightweight relevance signal, but they do not capture event materiality, novelty, or whether the article describes expected or surprising information. A future system could train a supervised event classifier, estimate event severity, and separate company-specific events from market-wide coverage.

Finally, social media remains future work rather than a completed experiment. Reddit is potentially feasible only through official API or approved research access with strict data-handling limits. X/Twitter is not a free broad-search option under the current official API model. If approved access becomes available, the next design should collect posts only through official channels, avoid redistribution of raw user content, map Arabic and English aliases for EGX tickers, and compare news-only, social-only, news-plus-social, and ensemble models under the same leakage-safe evaluation framework used in this thesis.
