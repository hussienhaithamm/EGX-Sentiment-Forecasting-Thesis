\section{Model Settings and Threshold Selection}

The direction models use standardized sentiment-side features and logistic regression with balanced class weights. The regularization parameter $C$ is selected from $\{0.01, 0.05, 0.1, 0.5, 1.0\}$ using validation walk-forward predictions only. The selection order uses F1, balanced accuracy, and raw accuracy. The thesis interpretation still prioritizes balanced accuracy because the test labels are imbalanced. Classification thresholds are chosen from validation predictions only. The threshold grid runs from 0.300 to 0.700 in steps of 0.025 and prioritizes balanced accuracy, then F1 and raw accuracy.

No test labels are used for hyperparameter or threshold selection. The repository stores the selected $C$ values and classification thresholds with the saved metrics:

\section{Supplementary Historical XGBoost Integration}

The sentiment-only results answer whether text alone carries directional information. A second question is whether the same sentiment signal adds value when it is appended to a historical EGX30 forecasting model. Table~\ref{tab:xgb_hybrid_results} reports this supplementary XGBoost experiment.

The historical-only variant uses EGX30 OHLCV-derived features from the historical forecasting pipeline. The augmented variant adds 49 lagged and rolling bilingual market-mood sentiment features. Both rows use the same chronological split, the same 425 test rows, and the same target labels. The test period is 16 May 2024 through 8 April 2026.

This is the clearest successful price-plus-sentiment result in the thesis artifacts. Adding sentiment to the historical XGBoost model improves raw accuracy by 6.4 percentage points, balanced accuracy by 3.6 percentage points, and F1 by 6.2 percentage points. AUC falls slightly, from 0.848 to 0.839, so the gain should be interpreted as an improvement in thresholded classification rather than a universal improvement in probability ranking.

The result does not replace the sentiment-only benchmark. Instead, it supports the practical interpretation that sentiment is more useful as an incremental feature in a historical model than as a standalone EGX30 direction signal.

\section{Robustness and Sanity Checks}

The robustness reports support the main interpretation rather than creating a separate research direction. Only 8 of 18 sentiment-model test rows beat the training-majority baseline on balanced accuracy. This prevents the thesis from claiming that sentiment consistently improves classification.

The abstention experiment asks whether predictions are more useful on high-signal days. The best row reaches balanced accuracy 0.580 at 35.6\% test coverage, with 72 covered test samples. This is a conditional finding: it suggests that stronger sentiment days may be more informative, but it does not replace full-session evaluation.

Sector-aware aggregation is implemented as a compact scaffold using a manually reviewable sector map that tolerates \texttt{UNKNOWN}. True historical EGX30 constituent weights are not available in the reproducible dataset, so index-weighted sentiment is not reported. No market-cap, price, return, or Open, High, Low, Close, Volume (OHLCV) proxy is used as a substitute.

\section{Interpretation and Limitations}

The results are useful, but they are not strong enough to support a trading claim. Balanced accuracy is close to 0.500 for several rows, and the best bilingual row reaches 0.545. This is above a random balanced baseline but far from strong directional discrimination.

The baseline results explain why this matters. Always-Up and majority baselines can look strong under raw accuracy because the sample contains an upward class bias. A thesis that selected results by raw accuracy would overstate the evidence. Selecting and interpreting results through balanced accuracy gives a more conservative conclusion.

Coverage also limits interpretation. The corpus is broad enough to support an index-level study, but some companies and sectors receive more news than others. Historical index weights are unavailable, so the thesis uses equal-weight market mood rather than claiming true index-weighted sentiment.

Bilingual financial-news sentiment from point-in-time EGX30 constituents appears to contain weak short-horizon directional information in some settings. The main value of the sentiment-only work is that it shows how to test that signal without look-ahead leakage or price-derived features. The supplementary XGBoost result then shows that the same signal can be more useful when added to a historical OHLCV model.

\section{Chapter Summary}

This chapter reported the final dataset, baselines, sentiment-only results, the supplementary XGBoost integration, robustness checks, and validity audit. The strongest standalone bilingual result is promising but limited, while the XGBoost integration provides a clearer successful incremental result. The validity audit supports the correctness of the evaluation protocol, and the metrics support a cautious claim: sentiment is weak alone but useful as an added historical-model feature. The next chapter concludes the thesis and identifies focused future work.
